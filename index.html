Questions

Good to know

Is TESSA really free?

Yes. It's free to use for personal, school and commercial writing. Everything you create belongs to you.

Do I need to install LaTeX first?

No. TESSA ships with its own LaTeX engine and fetches packages the first time a document needs them. TeX Live or MiKTeX are used automatically if you have them.

Does it upload my documents?

Never. TESSA has no servers. It only connects to download LaTeX packages it doesn't have yet, or when you look up a reference by DOI.

Is it open source?

No. TESSA is freeware: free to use, but it may not be modified, reverse engineered or resold. It's built on open-source components, which are listed in the third-party notices.

Which systems does it run on?

Windows 10 and 11, 64-bit. Use the installer, or the portable version if you can't install software on the computer.

I'm new to LaTeX. Is it for me?

Yes. The first-run setup tailors TESSA to beginners, and the optional 10-minute tour teaches the essentials by doing them.
