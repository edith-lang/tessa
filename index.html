One-click fixes

Errors explained in plain English, then fixed.

A typo like \titmle becomes \title with one click. A page full of errors? Press Fix all and TESSA repairs them and compiles again.

  • Misspelled commands and environments
  • Missing packages, braces, $ and \end{…}
  • Prices like $5, 50%, # and file paths in text
Layout mode

Drag anything, right on the PDF.

Press Ctrl L and move charts, images and text boxes where you want them on the page. TESSA rewrites the LaTeX for you.

  • Drag, drop and resize on the page
  • Works in documents and Beamer slides
Equations

See the formula before you insert it.

Click Σ, type your math and watch the preview build as you go. Inside math, shortcuts do the typing: @a becomes \alpha, // a fraction.

  • Live preview and a symbol palette
  • Numbered, inline or aligned
Tables and lists

Edit tables like a spreadsheet.

Paste cells from a spreadsheet and they become a LaTeX table. Click inside any table to sort, add rows or change alignment in a grid. Select lines and press Ctrl K to turn them into a list.

Questions

Good to know

Is TESSA really free?

Yes. It's free to use for personal, school and commercial writing. Everything you create belongs to you.

Do I need to install LaTeX first?

No. TESSA ships with its own LaTeX engine and fetches packages the first time a document needs them. TeX Live or MiKTeX are used automatically if you have them.

Does it upload my documents?

Never. TESSA has no servers. It only connects to download LaTeX packages it doesn't have yet, or when you look up a reference by DOI.

Is it open source?

No. TESSA is freeware: free to use, but it may not be modified, reverse engineered or resold. It's built on open-source components, which are listed in the third-party notices.

Which systems does it run on?

Windows 10 and 11, 64-bit. Use the installer, or the portable version if you can't install software on the computer.

I'm new to LaTeX. Is it for me?

Yes. The first-run setup tailors TESSA to beginners, and the optional 10-minute tour teaches the essentials by doing them.
